## 1. Introduction
Ce projet vise à développer un outil de résolution d'équations mathématiques, capable d'évaluer des expressions complexes et de fournir des résultats précis.

## 2. Fonctionnalités
- Résolution d'équations linéaires et quadratiques.
- Évaluation d'expressions arithmétiques et algébriques.
- Support pour les fonctions trigonométriques et logarithmiques.
- Interface utilisateur graphique intuitive.

## 3. Installation et Configuration
### Prérequis
- C++11 ou version ultérieure
- Un compilateur C++
- CMake (pour la configuration du projet)

### Installation
1. Cloner le dépôt sur votre machine :
   ```
   git clone https://github.com/votre_nom_de_utilisateur/projet_mathematique.git
   ```

2. Naviguer vers le répertoire du projet :
   ```
   cd projet_mathematique
   ```

3. Créer un dossier de build et y naviguer :
   ```
   mkdir build && cd build
   ```

4. Configurer le projet avec CMake :
   ```
   cmake ..
   ```

5. Compiler le projet :
   ```
   make
   ```

## 4. Utilisation
### Lancement de l'Interface Graphique
1. Naviguer vers le répertoire du build :
   ```
   cd build
   ```

2. Exécuter le programme :
   ```
   ./math_solver_ui
   ```

### Utilisation des Fonctionnalités
- Dans l'interface graphique, entrez une équation dans la zone de texte.
- Cliquez sur le bouton "Résoudre" pour obtenir le résultat.

Les contributions sont les bienvenues ! Voici quelques étapes à suivre :

1. Forker le dépôt sur GitHub.
2. Créer une nouvelle branche pour votre fonctionnalité ou correction :

3. Faire vos modifications et tester les changements.
